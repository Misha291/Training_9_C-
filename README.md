# Чётные числа от 1 до N

Простая консольная программа на C#, которая выводит все чётные числа от 1 до указанного пользователем числа включительно.

## Описание

Пользователь вводит целое число. Программа перебирает все числа от 1 до введённого и выводит те, которые делятся на 2 без остатка (чётные).

## Использование

1. Запустите программу.
2. Введите целое число.
3. Программа выведет все чётные числа от 1 до этого числа, разделённые пробелами.

## Пример

```
Введите число: 10
2 4 6 8 10
```

## Требования

- .NET SDK (версия 5.0 или выше) для компиляции и запуска.
- Любая среда разработки, поддерживающая C# (Visual Studio, Rider, VS Code).

## Заметки

- Если введено число меньше 1, программа не выведет ни одного числа (так как цикл не выполняется).
- Программа выводит числа в одну строку через пробел.
