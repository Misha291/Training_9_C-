# Чётные числа

Консольная программа на C#, которая выводит все чётные числа от 1 до введённого пользователем числа.

---

## Как работает

1. Пользователь вводит число **N**
2. Программа проверяет каждое число от 1 до N
3. Если число делится на 2 без остатка (`% 2 == 0`) — выводит его
4. Все числа выводятся в одну строку через пробел

---

## Пример работы

```
Введите число: 10
2 4 6 8 10
```

```
Введите число: 7
2 4 6
```

```
Введите число: 1

```

---

## Используемые концепции

- Цикл `for`
- Оператор остатка от деления `%`
- Условный оператор `if`
- Вывод в одну строку через `Console.Write()`
